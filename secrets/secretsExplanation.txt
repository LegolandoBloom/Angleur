Functions with Early Return of Restriction Types EXCLUDING "Map" : 
    These functions will always:
    - Have an Angleur_IsAddonSecretRestrictedForTypes("Combat", "Encounter", "ChallengeModes", "PvPMatch") early return right after InCombatLockdown() early return.
    These are then divided into 2 additional categories:
        (1) Ones WITH additional IsSecret() and ScrubSecret() checks built into them for cases where "Map" is restricted
                These sub-category functions will always:
                - Have at least one WoW-API Call querying Aura, Spell, Item, Container etc information: 
                - These WoW-API calls will be secret-proofed with individual IsSecret() and ScrubSecret() checks
                Functions List:
                    ____ Angleur.lua(+Classic Variants) ____
                    * Angleur_ActionHandler() 
                    ____ Angleur.lua(Retail Only) ____
                    * Angleur_FishingForAttentionAura()
        (2) Ones WITHOUT additional checks
                These sub-category functions will always:
                - Have ZERO WoW-API calls querying Aura, Spell, Item, Container etc information.
                - Have functionality that is guaranteed to be not-at-risk when map restrictions apply
                Functions List:
                    ____ Angleur.lua(+Classic Variants) ____ 
                    * Angleur_OnUpdate


Functions with Early Return of Restriction Types INCLUDING "Map" :
    These functions will always:
    - Have an Angleur_IsAddonSecretRestrictedForTypes("Combat", "Encounter", "ChallengeModes", "PvPMatch", "Map") early return right after InCombatLockdown() early return.
    - Will have NO Additional built-in secret checks.
    Functions List:
        ____ items_base ____
        * Angleur_GrabCursorItem
        * Angleur_GrabCursorMacro
        ____ toys_base ____
        * Angleur_ToyBoxOverlay_Activate

Functions that have NO Early returns, but have built-in secret checks:
    Functions List:
        ____ items_base ____
        * getNonSecretActiveAuraDataFromSlot()
        * retailToys:PickRandomToy -:
                                     + called by Angleur_ActionHandler() which has restriction based early return
                                     + called by CrateDropDownOnClick & RaftDropDownOnClick which have NO restriction based early returns 
        * Angleur_ActionHandler_ExtraItems - ONLY called by Angleur_ActionHandler() which has restriction based early return instead
            | 
            | _checkUsabilityItem()
            | _checkAuraOffset
            | _parseAndCheckMacroConditionals()
            | _checkAuraAndAuraOffsetDelay()
            | _checkAvailabilityOfSlotItem()
        ____ Angleur.lua(+Classic Variants) ____
        * ActionHandler_ExtraToys - ONLY called by Angleur_ActionHandler() which has restriction based early return instead
        * Angleur_ExtraItems_Auras() - Secret-Proofed by local functions it uses
            |
            | _grabAuraDurationOnFirstApplication()
            | getNonSecretActiveAuraDataFromSlot()
        * Angleur_Auras()
        * Angleur_ExtraToyAuras()
        ____ audio.lua ____
        * Angleur_RecastReminder_Start()


Functions that have NO Early Returns based on Restrictions OR built-in Secret Checks:
    These functions, despite initially seeming at risk due to restrictions are safe with just a InCombatLockdown() checks.
        Function Type List:
            * CVar Functions:
                - Functions that change CVars without needing to do WoW-API queries themselves
            * Functions that exist ONLY in Classic:
                - As they have no retail counterpart, so they won't have secret protection ported for retail parity
            * Functions/Snippets that change "Sleep" State:
                - Sleep state actually only changes UI elements, Certain CVars, and Angleur's own saved variables. No risky WoW-API calls are made and is safe from restrictions.
